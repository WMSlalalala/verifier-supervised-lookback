\section{Lessons}
\label{sec:lessons}
For within-task recall on mobile screens, keep the transcript. OCR text of every earlier screen fits in the context of a 14B model for the longest GUI-Odyssey trajectory. It beats a screen index by 14.5 localization points and 13.8 end-to-end points on 138 verified cases; on the long set a 7B reader keeps the localization ordering (\pval{0.21}). A trained writer cannot overtake it: one index line at the source screen already reaches full-history level, and the headroom in an oracle index is redundancy. Late needs stay open: on the long and held-out sets the localization lead shrinks to 8--12 points within noise and end-to-end accuracy has no winner. Any future study of this need should exclude steps whose answer is on the current screen and score any screen that carries the answer.
